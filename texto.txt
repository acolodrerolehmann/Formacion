Introducción:
El curso de Kubernetes está diseñado para proporcionar a los participantes los conocimientos y
habilidades necesarios para desplegar, gestionar y escalar aplicaciones en clústeres de
Kubernetes de manera eficiente. Se abordarán desde los conceptos básicos de orquestación de
contenedores hasta temas avanzados como gestión de aplicaciones con Helm y operadores,
políticas de red, actualización de pods en ejecución y extensibilidad mediante recursos
personalizados (CRDs).
Objetivos:
Al finalizar el curso, los participantes serán capaces de:
1. Comprender la arquitectura y componentes de Kubernetes, incluyendo pods, nodos,
servicios y APIs.
2. Instalar y configurar clústeres de Kubernetes en entornos locales u on-premise.
3. Desplegar y gestionar aplicaciones usando Helm, operadores y estrategias de
actualización de pods.
4. Configurar redes dentro de Kubernetes mediante Network Policies e Ingress,
asegurando la conectividad y seguridad de las aplicaciones.
5. Extender la funcionalidad de Kubernetes mediante Custom Resource Definitions
(CRDs) y operadores para automatizar tareas complejas.
6. Migrar aplicaciones y entornos desde Docker Swarm a Kubernetes, identificando
diferencias y buenas prácticas.
7. Organizar recursos y aplicaciones usando namespaces, aplicando aislamiento, gestión
de entornos y políticas de acceso.
8. Crear y gestionar pods, volúmenes, deployments, StatefulSets y DaemonSets para
aplicaciones con y sin estado.


Temario:
1.- Introducción a Kubernetes

2.- Componentes y arquitectura
    Pods: unidad mínima de despliegue.

Labels / selectors: organización y selección de pods.
Replication Controllers / ReplicaSets: mantener pods en ejecución.
Nodos: tipos y función dentro del clúster.
Servicios (Services): comunicación entre pods y exposición de aplicaciones.
APIs disponibles: interacción y automatización mediante la API de Kubernetes.

3.- Instalación de Kubernetes
Configuración on-premise / local para el producto Border &amp; Travel.
Herramientas de instalación (kubeadm, minikube, kind).
Validación de clúster y componentes básicos.
4.- Gestión de aplicaciones, redes y extensibilidad
    Despliegues con Helm / operadores
    o Uso de Helm para empaquetar aplicaciones.
    o Operadores para automatizar tareas complejas y gestión de aplicaciones.
 Redes y Network Policies
o Modelo de red en Kubernetes.
o Definición de políticas de red para control de tráfico entre pods.
 Ingress
o Exposición de servicios HTTP/HTTPS.
o Configuración de controladores de Ingress (NGINX, Traefik, etc.).
 Actualizaciones y migraciones de pods
o Estrategias de despliegue: rolling updates, canary, blue-green.
o Rollbacks y gestión de pods en ejecución.
 CRDs (Custom Resources)
o Extensión de la API de Kubernetes con recursos personalizados.
o Base para crear operadores y automatizar flujos complejos.

5.- Migración de Docker Swarm a Kubernetes
 Diferencias arquitectónicas y conceptuales.
Similaridades y facilidades de transición.

Puntos críticos y buenas prácticas para la migración.

6.- Namespaces
Concepto de namespaces y aislamiento de recursos.
Gestión de múltiples entornos en un mismo clúster.
Políticas de acceso y límites de recursos por namespace.

7.- Crear pods, volúmenes y despliegues
Pods: definición y creación manual.
Volúmenes: persistencia de datos, tipos de volúmenes (emptyDir, hostPath,
PersistentVolume).
Deployments: estrategias de despliegue, escalado automático y actualizaciones.
